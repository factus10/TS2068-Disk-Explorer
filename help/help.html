TS-2068 Disk Browser Help

Browse, view, edit, and extract files from vintage Timex Sinclair 2068 and ZX Spectrum disk images, tape files, and emulator snapshots.

Opening Files

Open a file using any of these methods:

  • Drag and drop onto the app window
  • Cmd/Ctrl+O or File → Open
  • File → Recent Files to reopen a previously viewed file
  • Double-click a supported file in Finder/Explorer (when app is installed)

The app auto-detects the format from file contents — no manual selection needed.

File Table

The file table shows all files on the disk with sortable columns (click column headers).

Selection

  • Click to select a single file
  • Cmd/Ctrl+Click for multi-select
  • Arrow Up/Down to navigate
  • Cmd/Ctrl+F to search/filter by filename

File Badges

  • PKG (red) — auto-detected TAP package
  • PKG (teal with pencil) — manually assembled package
  • DUMP — memory dump / state capture
  • EDITED — file has pending BASIC edits

Disk Map

Below the disk info, a color-coded grid shows block allocation. Each colored square represents a disk block assigned to a file. Gray squares are free blocks. Hover to see which file owns a block. The legend maps colors to filenames.

Content Viewers

Double-click a file or press Enter to open the viewer panel. Tabs auto-select the best view.

BASIC Listing

Syntax-highlighted program listing with line numbers.

  • Statements (PRINT, LET, IF) in cyan
  • Functions (SIN, PEEK, USR) in yellow
  • Operators (AND, OR) in orange
  • Disk commands (LOAD /, USR 100) in red with underline
  • TS2068 keywords (ON ERR, SOUND) in purple

Tokens toggle: Auto / TS2068 / Spectrum — controls interpretation of bytes 0x7B-0x7F (TS2068 keywords vs ZX Spectrum characters like { } ©).

Save PDF: exports the listing as a formatted PDF with syntax highlighting.

Copy: copies the entire listing as plain text.

Variables

Displays all BASIC variables with type badges (NUM, STR$, NUM(), STR$(), FOR). Arrays are expandable. FOR loops show value, limit, step, and loop line.

Cross-Reference (XRef)

Variable usage analysis:

  • SET line numbers — where the variable is assigned (LET, FOR, DIM, READ, INPUT)
  • USE line numbers — where the variable is read
  • Variables assigned but never read are flagged as unused
  • Filter box to search for specific variables

Screen (SCREEN$)

Renders 6912-byte CODE files as ZX Spectrum screens (256×192 with color attributes).

  • Invert — swap ink/paper colors
  • Prev/Next and Play/Stop — slideshow through all screens on the disk (3-second auto-advance)
  • Save PNG — export at 1x, 2x, or 4x scale

Font

Renders 768-byte CODE files as ZX Spectrum font character grids (96 characters, 8×8 pixels).

  • Live sample text preview — type to see text rendered in the font
  • Scale buttons (2x, 3x, 4x)
  • Save PNG — export the character grid
  • Save TTF — converts the bitmap font to a TrueType font file you can install on your computer

Array

Decodes numeric and character arrays with dimension info and values.

Text

Auto-detected for files with 90%+ printable ASCII content (word processor documents, plain text). Shows clean monospace text without hex columns.

Hex

Raw byte inspection with hex dump and ASCII representation. Always available as the last tab.

Inline BASIC Editing

Double-click any line in the BASIC listing to edit it.

  • Enter to confirm the edit
  • Escape to cancel
  • Edited lines show in teal with a revert arrow (↶)
  • Revert all link undoes all edits for the file
  • Files with edits show an EDITED badge in the file table

On extraction, only edited lines are re-tokenized — unedited lines preserve their original binary. This avoids re-tokenization ambiguities.

TAP Package Bundling

On disk systems each file is standalone, but on tape a BASIC program and the files it LOADs must appear sequentially in the same TAP file.

Auto-Detected Packages

The app scans BASIC programs for LOAD commands and matches them to catalog entries. Detected packages show a PKG badge. Click the expand arrow to see dependencies.

Supports: LOAD ""CODE, Oliger LOAD /"name", and Larken USR 100: LOAD "name".

Manual Package Assembly

Click Manual PKG in the toolbar to disable auto-detection.

  • Drag a file onto another to create a package
  • Drag within an expanded package to reorder
  • Drag from the main list into a package to add
  • Click × to remove a file from a package

State Captures & Snapshots

The app extracts BASIC programs from memory snapshots using system variable pointers (PROG/VARS at 0x5C53/0x5C4B).

Supported sources: Oliger type-4 state captures, SNA files (.sna), Z80 files (.z80).

  • Listing tab shows the extracted BASIC program
  • Variables tab shows runtime variable state
  • Extract BASIC button saves the program as a standalone .tap
  • SNA/Z80 snapshots also show the SCREEN$ at capture time

Extraction

  • Extract Selected — extract selected files individually
  • Extract as Package — export a package as a single multi-file TAP
  • Extract All — extract all files with auto-bundled packages, plus:
    • BASIC listings → .txt
    • Text/word processor files → .txt
    • Font files → .ttf
    • Screen files → .png

A manifest.md file is generated with disk metadata and file mapping.

If any BASIC files have pending edits, the edited versions are exported.

Batch Export

  • All Fonts button — exports all 768-byte font files as .ttf
  • All Screens button — exports all 6912-byte screen files as .png

Save PDF

On the Listing tab, click Save PDF to export a syntax-highlighted listing as a PDF document.

Create TAP

File → Create TAP (or Cmd/Ctrl+Shift+A) opens a dialog to build a TAP from external files:

  1. Click Add Files to select files from your computer
  2. Configure each file: name (max 10 chars), type (BASIC/CODE/Array), address or autostart line
  3. Use arrow buttons to reorder
  4. Click Save TAP

Disk Command Highlighting

The BASIC listing highlights DOS-specific I/O commands in red:

  • Oliger: OUT 244,1 ROM paging + LOAD /"name" syntax
  • Larken: USR 100 activation (after any keyword) + PRINT #4: channel shorthand + OPEN #4,"dd" setup
