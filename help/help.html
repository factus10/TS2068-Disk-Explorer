TS-2068 Disk Browser

Browse and extract files from vintage Timex Sinclair 2068 and ZX Spectrum disk images and TAP tape files.

Getting Started

Open a disk image or TAP file using Cmd/Ctrl+O, or drag and drop a file onto the window. The app auto-detects the format and displays the file catalog.

Click any file in the catalog to select it. Double-click or press Enter to open the content viewer. The viewer automatically selects the best view for the file type.

File Table

The file table shows all files on the disk with sortable columns (click column headers). Files are color-coded by type.

Selection

  • Click to select a single file
  • Cmd/Ctrl+Click for multi-select
  • Arrow Up/Down to navigate
  • Use the search box (Cmd/Ctrl+F) to filter files by name

File Type Badges

  • PKG — auto-detected TAP package (BASIC + dependencies)
  • DUMP — memory dump / state capture
  • EDITED — file has pending BASIC edits

Content Viewers

The side panel opens when you double-click a file or press Enter. It auto-selects the best view with tabs to switch between views.

BASIC Listing

Syntax-highlighted BASIC program listing with line numbers. Keywords are color-coded:

  • Statements (PRINT, LET, IF, etc.) in cyan
  • Functions (SIN, PEEK, USR, etc.) in yellow
  • Operators (AND, OR, etc.) in orange
  • Disk commands (LOAD /, RANDOMIZE USR 100, etc.) in red with underline
  • TS2068 keywords (ON ERR, SOUND, STICK, etc.) in purple

The Tokens toggle (Auto / TS2068 / Spectrum) controls how bytes 0x7B-0x7F are interpreted — as TS2068 extended keywords or ZX Spectrum characters.

Variables

Displays all BASIC variables with their types, values, and array contents. Available for BASIC programs and state captures.

Screen

Renders 6912-byte CODE files as ZX Spectrum screens (256x192 with color attributes). Includes invert toggle and PNG export at 1x/2x/4x scale.

Font

Renders 768-byte CODE files as ZX Spectrum font character grids (96 characters, 8x8 pixels each). Includes a live sample text preview, PNG export, and Save TTF to convert the bitmap font to a TrueType font file.

Array

Decodes numeric and character arrays with dimension info and values.

Text

Auto-detected for files with 90%+ printable ASCII content (word processor documents, plain text). Shows clean monospace text without hex columns.

Hex

Raw byte inspection with hex dump and ASCII representation. Always available as the last tab.

Inline BASIC Editing

Double-click any line in the BASIC listing to edit it. Edited lines are shown in teal.

  • Enter to confirm an edit
  • Escape to cancel
  • Click the revert arrow (↶) on an edited line to undo that edit
  • Click Revert all to undo all edits for the file

Edits are tracked per-file across the entire disk. On extraction, only edited lines are re-tokenized — unedited lines preserve their original binary.

TAP Package Bundling

On disk systems each file is standalone, but on tape (TAP format) a BASIC program and the files it LOADs must appear sequentially.

Auto-Detected Packages

The app scans BASIC programs for LOAD commands and matches them to catalog entries. Packages show a PKG badge. Click the expand arrow to see dependencies.

Manual Package Assembly

Click Manual PKG in the toolbar to disable auto-detection and work with a flat file list.

  • Drag a file onto another to create a package
  • Drag within an expanded package to reorder
  • Drag from the main list into a package to add
  • Click the x button on a dependency to remove it

Manual packages show a teal badge with a pencil icon.

State Captures

Oliger type-4 state captures contain full memory snapshots. The app extracts the BASIC program using system variable pointers (PROG/VARS) and shows it in the listing viewer.

Click Extract BASIC in the viewer header to save the extracted program as a standalone TAP file.

Extraction

  • Extract Selected — extract selected files individually
  • Extract as Package — export a package as a single multi-file TAP
  • Extract All — extract all files, bundling auto-detected packages

A manifest.md file is generated alongside extracted files with disk metadata and a file mapping table.

If any BASIC files have pending edits, the edited versions are exported.

Disk Command Highlighting

The BASIC listing highlights DOS-specific I/O commands:

  • Oliger: OUT 244,1 ROM paging + LOAD /"name" syntax
  • Larken: USR 100 activation + PRINT #4: channel shorthand + OPEN #4,"dd" setup
